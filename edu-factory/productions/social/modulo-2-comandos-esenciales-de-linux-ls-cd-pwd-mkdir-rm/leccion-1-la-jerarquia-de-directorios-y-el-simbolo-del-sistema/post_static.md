## Copy para la publicación

El prompt y la carpeta personal (~) es la parte que más se salta y la que más problemas provoca después. En la lección 1 de Termux desde Cero: Domina la terminal en tu Android lo desarmamos en el orden correcto, con el proceso en pantalla.

En esta lección: El prompt y la carpeta personal (~); pwd para saber el directorio actual; cd para cambiar de carpeta y volver con cd ~. El prompt `~ $` indica que Termux está en la carpeta personal. La raíz del sistema Termux es `$PREFIX` (normalmente /data/data/com.termux/files/usr), no `/`. Saber dónde estás es el primer paso para no borrar nada por accidente. Al terminar te llevas un ejercicio concreto para practicar: Recorre la jerarquía con cd y vuelve siempre a la carpeta personal con cd ~.
