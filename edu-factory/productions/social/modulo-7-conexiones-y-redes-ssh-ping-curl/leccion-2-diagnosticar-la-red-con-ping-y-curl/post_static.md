## Copy para la publicación

Medir la conectividad con ping -c es la parte que más se salta y la que más problemas provoca después. En la lección 2 de Termux desde Cero: Domina la terminal en tu Android lo desarmamos en el orden correcto, con el proceso en pantalla.

En esta lección: Medir la conectividad con ping -c; Ver cabeceras HTTP con curl -I; Depurar con curl -v y --max-time. ping comprueba si un host responde midiendo latencia, y curl hace peticiones HTTP. El trío ping, curl -I y curl -v da una imagen de si el problema es la red o el servidor. Al terminar te llevas un ejercicio concreto para practicar: Diagnostica tu conexión haciendo ping a 1.1.1.1.
