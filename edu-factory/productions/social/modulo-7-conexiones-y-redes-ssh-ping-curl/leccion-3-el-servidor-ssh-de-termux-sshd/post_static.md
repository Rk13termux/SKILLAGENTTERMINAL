## Copy para la publicación

Arrancar el daemon con sshd es la parte que más se salta y la que más problemas provoca después. En la lección 3 de Termux desde Cero: Domina la terminal en tu Android lo desarmamos en el orden correcto, con el proceso en pantalla.

En esta lección: Arrancar el daemon con sshd; Conocer tu IP local con ifconfig o ip addr; Detener el servicio con pkill sshd. Termux puede servir como servidor: con sshd cualquiera con tu IP y contraseña se conecta a tu teléfono. Se levanta bajo demanda y se detiene cuando ya no se necesita. Al terminar te llevas un ejercicio concreto para practicar: Levanta sshd, localiza tu IP y conéctate desde otro dispositivo.
