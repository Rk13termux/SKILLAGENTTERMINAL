## Intro (0:00 - 0:30)

**Gancho:**
«El gestor pkg y sus subcomandos (install, remove, search)» es lo que separa un resultado reproducible de uno que depende de la suerte. En esta lección (Python desde el gestor de paquetes pkg) lo vemos completo, con el proceso en pantalla.

**Presentación del problema:**
Problema real: principiantes absolutos, estudiantes y entusiastas de la tecnología que quieren programar desde su celular suelen bloquearse con El gestor pkg y sus subcomandos (install, remove, search) porque falta el orden de pasos. pkg es el gestor que empaqueta la colección de Termux. Instalar Python trae también pip, y con python -m venv creas entornos aislados para cada proyecto sin ensuciar el sistema. Hoy cerramos ese hueco en pocos minutos.

## Demostración práctica paso a paso

**Paso 1.** Ejecuta y muestra:

```
pkg install python
```

**Paso 2.** Ejecuta y muestra:

```
python --version
```

**Paso 3.** Ejecuta y muestra:

```
pip --version
```

**Paso 4.** Ejecuta y muestra:

```
python -m venv mi-proyecto/venv
```

**Paso 5.** Ejecuta y muestra:

```
source mi-proyecto/venv/bin/activate
```

**Verificación.** Compara el resultado en pantalla con el esperado antes de avanzar.

## Errores comunes y cómo evitarlos

- **Saltarse «El gestor pkg y sus subcomandos (install, remove, search)».** Sin ese punto, el resto del proceso falla de forma silenciosa. Verifícalo antes de continuar.
- **Copiar comandos sin leerlos.** Revisa cada opción antes de ejecutar: un parámetro mal puesto cambia el resultado.
- **Practicar una sola vez.** En un nivel principiante a intermedio el proceso se consolida repitiéndolo hasta que salga sin guion.
