## Copy para la publicación

El ciclo status > add > commit es la parte que más se salta y la que más problemas provoca después. En la lección 1 de Termux desde Cero: Domina la terminal en tu Android lo desarmamos en el orden correcto, con el proceso en pantalla.

En esta lección: El ciclo status > add > commit; Mensajes de commit claros; Leer el historial con git log. El flujo diario es ver (git status), preparar (git add) y guardar (git commit). git log registra la historia y git diff muestra qué cambió antes de confirmar. Al terminar te llevas un ejercicio concreto para practicar: Crea dos commits con mensajes distintos sobre el mismo proyecto.
