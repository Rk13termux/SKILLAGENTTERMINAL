## Copy para la publicación

Generar una clave con ssh-keygen es la parte que más se salta y la que más problemas provoca después. En la lección 2 de Termux desde Cero: Domina la terminal en tu Android lo desarmamos en el orden correcto, con el proceso en pantalla.

En esta lección: Generar una clave con ssh-keygen; Añadir la clave pública a GitHub; Enlazar, publicar (push) y descargar (clone). Con una clave SSH (ed25519), git habla con GitHub sin contraseña. La clave se copia en GitHub y luego el repositorio remoto se enlaza con git remote add. Al terminar te llevas un ejercicio concreto para practicar: Genera tu clave, cópiala en GitHub y haz tu primer push.
